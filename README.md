# Simple Todo App

A clean and functional Todo application built as part of the TripleTen Software Engineering program.

## Functionality

- Add new tasks
- Mark tasks as completed
- Delete tasks


## Technology

- HTML5
- CSS3 (with BEM methodology)
- JavaScript
